# Portfolio site

Personal portfolio (screenwriting, music/audio, film). Static HTML/CSS with minimal JS, deployed to Netlify. No build step.

## Read at the start of any session
1. [PRODUCT.md](PRODUCT.md): purpose, audience, constraints, principles, open decisions.
2. [DECISIONS.md](DECISIONS.md): what has already been settled. Don't re-litigate these.
3. [references/README.md](references/README.md): index of visual references, with notes on what to take from each. Look at the files in `references/images/` before doing design work.

## Rules
- Use only real, owner-supplied work and credits. Never fabricate projects, press or testimonials.
- When a design or product decision is settled, append it to DECISIONS.md.
- When the user adds a reference, add or update its entry in references/README.md (ask what they like about it if unclear).
