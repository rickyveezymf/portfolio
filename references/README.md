# Visual References

Index of inspiration for the portfolio site. Put files in `images/` (screenshots, exports) and add an entry below for each one.

The note matters more than the image: say **what to take from it** and **what to ignore**.

## Entry template

### <short name>
- **File / link:** `images/<file>` or URL
- **Take:** what I like (layout, type, color, motion, tone...)
- **Ignore:** what not to copy
- **Applies to:** home / work page / about / contact / global
